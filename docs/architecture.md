# Target architecture

Bengali meme
- Image pathway: ViT/CLIP visual representations
- Text pathway: Bengali OCR followed by BanglaBERT
- Cultural context module
- Image-text interaction/consistency module
- Evidence retrieval
- Claim-evidence verification
- Reliability-aware fusion and decision policy
- Grounded explanations

Original text/image features remain accessible to the decision head.
Missing evidence is not automatically a refutation.
Diagram components are design targets, not claims of completion.
